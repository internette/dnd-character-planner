Two families, both OFL-licensed: **Lora** for headings, names and numerals, and **Public Sans** for running text, labels and captions. Sizes and line heights count 4px steps, like spacing: `--font-size-4` is 16px and `--line-height-6` is 24px.

Use a named text style wherever one fits: `font: var(--type-body)`. Where none does, compose one from the scale tokens. `label` is always uppercase, applied with `text-transform` (the `.cp-label` class), never by uppercasing the text.
