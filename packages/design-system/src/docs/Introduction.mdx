Character Planner is the design system for the D&D Character Planner. It ports the Ciaccona Lore Bard roadmap: a forest-green hero, calm cards on a soft ground, and a three-color phase language for crowd control. Every product screen in `apps/web` builds from it first.

## Principles

1. **Everything sits on a 4px grid.** Sizes, line heights, padding, gaps, margins and radii are multiples of 4px and come from tokens. Strokes (1px, 2px) are the only exception.
2. **The rules are the content.** Every spell, feat or feature shows its source book and level in its meta line (`XGtE · 5th · Druid · Concentration`). Anything the table must decide gets the `dm` chip.
3. **Phase is a language.** A pick's role in the loop is always shown with its word. Color supports the word and never replaces it.
4. **The player decides.** Recommendations are marked *Recommended*, with alternatives directly under them. Nothing reads as a requirement.

## Install and import

The package lives in this monorepo as `@dnd/design-system`. Add it to a workspace with `"@dnd/design-system": "workspace:*"`, then import the styles once and the components where you need them:

```tsx
import "@dnd/design-system/styles.css";
import { PageHero } from "@dnd/design-system";
```

`styles.css` includes the tokens, the shared `cp-` classes and every component's styles. Use `@dnd/design-system/tokens.css` for the tokens alone. Fonts load from `@dnd/design-system/fonts.css`, unless the app loads Lora and Public Sans itself (the web app uses `next/font`).

Light is the default theme. Set `data-theme="dark"` on any ancestor to switch a subtree to dark. In this Storybook, use the theme switch in the toolbar.

## Contributing

Read [CONSTITUTION.md, Part II §4 ("Build on the design system")](https://github.com/internette/dnd-character-planner/blob/main/CONSTITUTION.md#4-build-on-the-design-system) before building product UI. Use what the system offers first. When a feature needs something it doesn't cover, stop and ask whether it belongs in the system or in the product. Every component ships with a spec, a story and an MDX page.
