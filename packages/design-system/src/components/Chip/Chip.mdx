## Variants

Every color is a variant. Set the text with `value`.

<Canvas of={Stories.AllFacts} />

- `neutral`: features gained, such as 5th-level spells or Song of Rest d8.
- `instant`: casting properties such as Instant and No concentration.
- `concentration`: the Concentration casting property.
- `dm`: anything the table must approve, such as non-core sources.

## Phases

The `gather`, `hold` and `strike` variants mark which step of the crowd-control loop a pick serves. Leave `value` empty and the chip shows the phase word.

<Canvas of={Stories.AllPhases} />

- **Gather** pulls enemies together.
- **Hold** keeps them there.
- **Strike** hits the group.

Use the `md` pill on level cards (top row) and the default `sm` square in lists and tables (bottom row). [Phase language](?path=/docs/patterns-phases--docs) shows how the loop works across a page.

## Content rules

- Write `value` in sentence case. Every variant except `neutral` is uppercased by CSS.
- Use `dm` whenever the group must approve something, because the table has the final word.
- Never show a phase by color alone. A custom `value` on a phase chip must still contain the phase word, for example "Strike · AoE".

## Accessibility

The text is the content, so chips need no ARIA. They aren't interactive. Every variant's text and fill pass 4.5:1 in both themes.
