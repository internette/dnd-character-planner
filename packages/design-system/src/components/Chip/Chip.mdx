## Phase variants

The `gather`, `hold` and `strike` variants mark which step of the crowd-control loop a pick serves. They show the phase word when `value` is left empty.

<Canvas of={Stories.AllPhases} />

- **Gather** pulls enemies together.
- **Hold** keeps them there.
- **Strike** hits the group.

Use the `md` pill on level cards and the default `sm` square in lists and tables.

<Canvas of={Stories.Gather} />

<Canvas of={Stories.PhaseSmall} />

See [Phase language](?path=/docs/patterns-phases--docs) for how the loop works across a page.

## Content rules

- Use `dm` whenever the group must approve something. The table has the final word (constitution Part I §3).
- Write `value` in sentence case. Every variant except `neutral` is uppercased by CSS.
- Never show a phase by color alone. If you set `value` on a phase chip, it must still contain the phase word, for example "Strike · AoE". The component doesn't check this, so check it in review.

## Accessibility

The text is the content. Chips aren't interactive and need no ARIA. Each variant's text and fill pass 4.5:1 in both themes.
