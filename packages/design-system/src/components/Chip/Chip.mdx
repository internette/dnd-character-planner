## Variants

Each variant is a color. The text is whatever you pass as `value`, exactly as written.

<Canvas of={Stories.AllVariants} />

- `green`: features gained and casting properties.
- `amber`: Concentration, and the Hold phase.
- `purple`: anything the table must approve, such as a non-core source.
- `blue`: the Gather phase.
- `red`: the Strike phase.

<Canvas of={Stories.AllFacts} />

## Shapes

`rectangle` is the default, for lists and tables. Use `pill` for the phase on a level card.

<Canvas of={Stories.Shapes} />

## Content rules

- Write `value` in sentence case. The chip never changes it.
- Use `purple` whenever the group must approve something, because the table has the final word.

## Accessibility

The text is the content, so chips need no ARIA, and they aren't interactive. Every variant's text and fill pass 4.5:1 in both themes.
