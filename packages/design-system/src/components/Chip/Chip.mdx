## Variants

Each variant is a color. `plain` is regular weight; the rest are semibold. Set the text with `value`; it shows exactly as you write it.

<Canvas of={Stories.AllFacts} />

- `plain`: features gained, such as 5th-level spells or Song of Rest d8.
- `green`: casting properties such as Instant and No concentration.
- `amber`: Concentration, and the Hold phase.
- `purple`: anything the table must approve, such as non-core sources.
- `blue` and `red`: the Gather and Strike phases.

## Phases

Gather, hold and strike mark which step of the crowd-control loop a pick serves. `PHASE_VARIANT` gives each phase's variant and `PHASE_LABEL` its word, so every phase chip matches.

<Canvas of={Stories.AllPhases} />

- **Gather** pulls enemies together.
- **Hold** keeps them there.
- **Strike** hits the group.

Use the `md` pill on level cards (top row) and the default `sm` square in lists and tables (bottom row). [Phase language](?path=/docs/patterns-phases--docs) shows how the loop works across a page.

## Content rules

- The chip never changes the case of `value`. Use sentence case, as in the examples.
- Use `purple` whenever the group must approve something, because the table has the final word.
- Never show a phase by color alone. A phase chip's `value` always contains the phase word, for example "Strike" or "Strike · AoE".

## Accessibility

The text is the content, so chips need no ARIA. They aren't interactive. Every variant's text and fill pass 4.5:1 in both themes.
