## Content rules

- The title is an evocative name for the level.
- Features are the level's class features, one chip each.
- Give each level one phase.
- Use two picks side by side only on Magical Secrets levels.
- Every pick names its source book and edition.
- List at most three alternatives.

## Accessibility

Each level card is an `article` labelled by its title, which is an `h3`; pick names are `h4` under it. The level badge reads as "Level N". The phase chip shows the phase word, so color is never the only signal.
