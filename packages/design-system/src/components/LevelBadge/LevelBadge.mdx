## In use

LevelBadge is only used inside LevelCard, where it sits to the left of the card. Two-digit levels fit inside the disc.

## Accessibility

Screen readers hear the disc as one image named "Level 9". The "LEVEL" label and the numeral are hidden from them so the level isn't read twice.
