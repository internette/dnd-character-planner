`--space-N` is N × 4px. Use only these steps; never hand-type a value between them. There are no 2px or 6px nudges. `space-12` (48px) is the minimum height and width of anything tappable.

## Spacing

<TokenTable css={spacingCss} variant="space" />

## Radii

Radii are on the 4px grid. Pills are 24px tall with `radius-xl`; discs use `radius-full`.

<TokenTable css={shapeCss} variant="radius" prefix="--radius-" />

## Strokes

Strokes are the one exception to the 4px rule, because they are lines, not space. Cards get a hairline border and no shadow; there are no shadow tokens.
